Emberfall Arena — a neon top-down arena shooter. A little ember wisp fights ten waves of drifters, rushers and shooters: telegraphed spawns, chained combos, close-range bonuses, pickups and a shield, to the sound of synthesised WebAudio. Best score is kept in the browser's local storage on the player's own machine — there is no leaderboard and no network request.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
